# Production Java review — 2026-10-31

## Scope and method

Four agents divided the 68 Java files under the actual shared production source root, `abacus-da-all/src/main/java`. The other Maven modules compile subsets of that tree. The review covered implementations and nested classes, API contracts and Javadocs, resource ownership, conversion boundaries, asynchronous delegation, iteration costs, and allocation behavior. Changes were limited to findings supported by code inspection, driver/library contracts, or regression tests.

## Confirmed findings and changes

| Area | Trigger and previous behavior | Change and regression coverage |
| --- | --- | --- |
| DynamoDB SDK v1/v2 | Collection rows requested as `ArrayBlockingQueue` failed because the no-argument factory cannot construct that class. | Size queues to the row width, with minimum capacity one for empty rows. Tests cover single-item, list, empty-row, and null behavior. |
| DynamoDB SDK v1/v2 | Appending each attribute to a `CopyOnWriteArrayList` copied every preceding value. | Populate a temporary array-backed list and construct the requested list once. Tests cover order, duplicates, nulls, binary values, and allocation growth. |
| Cassandra driver v3/v4 | A scalar stream cached whether its first decoded value was assignable to the target type. Later nulls or values of a different runtime type could bypass required conversion. | Check assignability for every row. Tests cover optional/null defaults and changing custom-codec value types in both driver generations. |
| Cassandra driver v3 | UDT field-type lookup repeatedly traversed all preceding fields. | Advance the field metadata iterator alongside positional values. The regression checks traversal counts and time/collection decoding. |
| MongoDB sync/reactive | A synchronous scalar stream retained a mutable projection collection; later edits could change the field decoded from rows. Dotted paths were split again for every row. | Capture the selected projection and parse its path once per mapper. Tests cover projection replacement/clearing and missing/null nested values. |
| BigQuery | Bounded-queue rows and native repeated values could not be constructed; immutable bean finalization could reconstruct an empty queue with capacity zero. | Construct queues with usable capacity, finalize collection types consistently, and avoid reconverting an already decoded repeated value. Tests cover list/stream/registered conversion, empty values, timestamp precision, and annotation-driven scalar conversion. |
| BigQuery | Copy-on-write rows and native repeated collections copied their entire prefix on each insertion. | Buffer and construct once. Tests verify the requested collection type, ordering/null rules, and linear row-allocation growth. |
| Neo4j | Filter-copy fallback returned an already consumed single-use iterable after encountering an unsupported filter. | Snapshot non-collection iterables before inspection. Tests cover unsupported subclasses, null filters, empty inputs, and successful indexed copies without modifying originals. |
| HBase delete wrappers | An extra family-map lookup could throw before HBase validated a negative timestamp. | Detect newly created families using the family count, preserving rollback while removing the lookup. A regression exercises all eight explicit-timestamp marker overloads. |
| HBase versioned properties | A copy-on-write list copied every earlier version for each cell read. | Buffer additions and append once to the original factory instance. Tests cover top-level/nested properties, immutable beans, subclass behavior, and allocation growth. |

Complex conversion, fallback, and bulk-construction changes have explanatory comments. Parameter-validation behavior is covered by tests without adding explanatory validation comments.

Javadocs now describe collection semantics, asynchronous execution/threading limits, MongoDB projection snapshots, Neo4j iterable materialization, HBase scan memory behavior, and Cosmos conditional-write/background-deletion behavior. Cassandra builder and mapper documentation was checked alongside its implementation; structural spacing issues were corrected.

Added 47 regression test invocations across nine new test classes and four existing Cassandra test classes. Also updated one existing exact-message assertion to match the pre-existing abacus-query 4.9.7 dependency: empty entity maps now report `entity map must not be empty`. The exception type and all insert-behavior assertions remain in place.

The MongoDB/HBase reviewer independently checked the BigQuery and Neo4j changes; that review prompted a narrower BigQuery immutable-value optimization plus an annotation-conversion regression. The AWS reviewer independently checked the Cassandra conversion and UDT changes against the pinned driver sources.

## Limits

The `*IT` live-service suites were not selected. The default suite also contains MongoDB tests that probe localhost and skip when MongoDB is unavailable; those tests were skipped here. No successful live-service integration validation is claimed. Allocation tests measure per-thread allocated bytes on the supported JDK; they do not establish end-to-end throughput or production heap usage. Illustrative Javadoc snippets were reviewed but not all independently compiled or executed. The inventory records review coverage, not a guarantee that unchanged code is defect-free.
